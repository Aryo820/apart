# PRD - Apartment Booking Website

## Tujuan
Membangun website booking apartemen dengan tampilan profesional untuk meningkatkan personal branding.

## Target Pengguna
- Calon penyewa
- Admin

## Fitur MVP
### User
- Landing page
- Daftar apartemen
- Detail apartemen
- Pencarian & filter
- Booking form
- Login/Register
- Riwayat booking
- Pembayaran (Midtrans)

### Admin
- Dashboard
- CRUD Apartemen
- CRUD Fasilitas
- Kelola Booking
- Kelola Pembayaran
- Kelola User
- Statistik sederhana

## Tech Stack
- Laravel 12
- Filament
- MySQL
- Midtrans
- Tailwind CSS

## Non Functional
- Responsive
- SEO dasar
- Validasi form
- Keamanan auth
